# פינת הכתיבה — sandgame

אפליקציית תרגול כתיבה במסך מגע (אותיות, מספרים, מעורב) למטפלים העובדים עם
ילדים על הספקטרום. קובץ HTML יחיד, ללא בנייה (build), פועל ישירות מ-GitHub Pages:
https://lanchi10.github.io/sandgame/

## מבנה התיקייה

```
sandgame/
├── index.html              # האפליקציה כולה (HTML + CSS + JS)
├── README.md
└── assets/
    ├── backgrounds/         # רקעים דקורטיביים לכל עולם (SVG)
    │   ├── jungle-bg.svg
    │   ├── rainbow-bg.svg
    │   ├── candy-bg.svg
    │   ├── construction-bg.svg
    │   ├── racing-bg.svg
    │   └── snow-bg.svg
    └── characters/           # "דמויות" אנימציית הניקוי השמח (SVG)
        ├── dino.svg
        ├── unicorn.svg
        ├── candy-piece.svg
        ├── bulldozer.svg
        └── race-car.svg
```

עולם השלג (`snow`) אינו משתמש בדמות — אנימציית הניקוי שלו היא שלג יורד
ומצטבר, מצויר ישירות ב-canvas.

## איך השימוש זורם

1. **מסך פתיחה** — המטפל/ת בוחר/ת סוג תרגול (אותיות / מספרים / מעורב)
   ועולם רקע, ולוחצ/ת "▶ התחלה".
2. **מסך תרגול** — נשאר מינימלי לחלוטין: אזור כתיבה גדול במרכז, וארבעה
   כפתורים בלבד:
   - 👁️ הצג / 🙈 הסתר — מציג או מסתיר את האות/הספרה הנוכחית (ברירת מחדל: מוסתר).
   - ניקוי שמח (תלוי-עולם, למשל "🦕 הדינוזאור מנקה") — אנימציית ניקוי רגועה.
     **אותו פריט נשאר פעיל** אחריה.
   - 🧹 ניקוי רגוע — ניקוי מיידי, ללא אנימציה.
   - ➡️ פריט הבא — מעבר לאות/ספרה הבאה.
   - כפתור ⚙ קטן בפינה — חזרה למסך הפתיחה.

## עולמות

קיימים (ללא שינוי): חול, אש קסומה, נהר, כדורגל.
חדשים: ג'ונגל (דינוזאור), קשת (חד-קרן), ממתקים, בנייה (דחפור), מרוץ
מכוניות, שלג. לכל עולם רקע, צבעי כתיבה, וצבע "ניקוי שמח" משלו, בעיצוב
רגוע ללא הבהובים, רעשים או תזוזות חדות.

## החלפת תמונות (Assets)

כל קובצי ה-SVG הם **placeholders** פשוטים — אפשר להחליף כל אחד בקובץ
משלכם, **באותו שם קובץ** (ובמידת האפשר אותו יחס רוחב-גובה), בלי לגעת בקוד:

- `assets/backgrounds/*.svg` — נטענים כרקע שקוף-למחצה סביב אזור הכתיבה
  (לא במרכז, כדי לא להפריע לכתיבה).
- `assets/characters/*.svg` — נטענים כדמות שחולפת על המסך באנימציית
  "הניקוי השמח".

ניתן להשתמש גם ב-PNG/JPG במקום SVG — רק לעדכן את הסיומת בנתיב בתוך
`ASSETS` ב-`index.html` (חיפוש לפי `assets/backgrounds/` ו-
`assets/characters/`).

## תאימות

נבדק מול: iPhone Safari, iPad Safari, Android Chrome, Chrome שולחני.
משתמש ב-Pointer Events + `setPointerCapture` + `touch-action: none` כדי
שהכתיבה באצבע תעבוד חלק וללא גלילה לא רצויה.
